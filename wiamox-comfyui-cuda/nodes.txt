# Custom nodes bundled into wiamox-comfyui-cuda.
#
# Format: <git-url>  <target-directory-name>  <tag|branch|commit>
# Every row is PINNED to the commit that was current on 04.10.2026, so two
# builds of the same ComfyUI version give the same nodes. To update a node:
#   git ls-remote <git-url> HEAD      # copy the hash into the 3rd column
# then bump pkgrel, rebuild and test. Rows without a 3rd column track the
# default branch (not reproducible - avoid).
#
# ComfyUI-Manager is deliberately NOT bundled: it only works online (it
# installs nodes and models from the internet) and would try to.
# The nodes' Python dependencies are installed into the package at build
# time, so none of this needs a network on the user's machine.
