# Changelog

## 1.0.0 — 29.10.2026

First version of woxmon (WiamOX Monitor).

- Terminal system monitor: CPU, memory, disks, network, GPU (NVIDIA, AMD, Intel) and processes.
- WiamOX name, logo, icon, desktop entry (`com.wiamox.woxmon`), man page, help and config texts.
- Linux only.
- GPU box shown by default; hidden for one run when there is no GPU or the
  terminal is too small, without changing the config file.
- Config in `~/.config/woxmon/woxmon.conf`, log in `~/.local/state/woxmon.log`.
